# Промпт для продолжения работы

Продолжи работу в `/opt/chromium-gost-powershell-installer`.

Нужно реализовать минимальный надежный публичный PowerShell-инсталлятор Chromium-GOST для запуска непосредственно на Windows-хосте. Прочитай `PLAN.md` и соблюдай его ограничения. Репозиторий универсальный: не упоминай AVS, DVLS, Zabbix, внутренние хосты, учетные данные или конкретного заказчика.

Сначала проверь актуальный интерфейс и поведение публичного GitHub-репозитория `deemru/Chromium-Gost`, затем создай `Install-ChromiumGost.ps1` и краткий `README.md`. Скрипт должен скачать подходящий Windows x64 installer, проверить его, выполнить системную тихую установку/обновление, проверить результат, вести понятный лог и возвращать ненулевой код при ошибках. Поддержи pin версии и SHA-256, но не усложняй решение без необходимости.

Работай короткими проверяемыми шагами: сначала просмотр файлов, затем реализация, затем PowerShell-синтаксическая проверка и минимальные тесты. Не создавай удаленный оркестратор и не добавляй сторонние зависимости.
